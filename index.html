Shorts Profit Lab

Shorts Profit Lab is a private publishing tool run by Zack Martin. It posts short-form videos that we create or are authorized to use to social media accounts that we own or manage with the account holder's permission, using each platform's official API.

What it does

  • Uploads videos and captions to connected YouTube, Instagram, TikTok and LinkedIn accounts.
  • Reads basic profile details of connected accounts (name, handle, account ID) to confirm which account it is posting to.
  • Reads performance statistics for videos it posted, to decide what to make next.

It is not offered to the public. Only accounts we operate, or whose owners have authorized us, are connected.
